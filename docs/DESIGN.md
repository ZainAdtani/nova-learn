# Nova Learn brand

## Colors

| Name | Hex | Use |
|---|---|---|
| Dark Nova | `#0A0F1A` | main background |
| Spidey Blue | `#447BBE` | primary buttons, links |
| Claude Orange | `#D97706` | streak flame, warm accents |
| Sunset Drive | `#DD5013` | secondary accent |
| Fresh Hay | `#E9E4A6` | small highlights |
| White | `#FFFFFF` | text on dark backgrounds |

**Never use:** `#00D4AA`, `#3B82F6`

## Fonts

- Headlines (H1/H2): Luckiest Guy
- Subheads (H3): Plus Jakarta Sans ExtraBold
- Body text: DM Sans
